## Project Overview

KHAAB is a fashion brand selling premium women's bags. The client needed 
a fully functional, visually polished Shopify store with custom design 
elements that went beyond what the original theme offered out of the box.

This was a real paid freelance project — not a tutorial or practice project.

---

## What I Did

- Set up and configured the complete Shopify store from scratch
- Customized the theme to match the client's brand requirements
- Built custom design sections using code that were not available in the original theme
- Modified layouts and styling across multiple pages
- Ensured full mobile responsiveness on all custom components
- Handled multiple rounds of client-requested revisions
- Delivered the final store on time and to the client's satisfaction
